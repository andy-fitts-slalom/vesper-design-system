# Changelog

## 3.0.0 — 2026-10-01

Visual direction selected from the Frame exploration: pale cool-gray salt-flat canvas, Barlow Condensed display typography, and petrol emphasis. Shared light-theme defaults change; all three applications retain their separate layouts, data, routes and behavior.

## 2.0.0 — 2026-09-30

Breaking Vesper identity update: parent and product naming, original V-and-star mark, desert sand / sky / petrol / coral palette, renamed package and exports, `vs-` CSS contract, refreshed preview and three upgrade handoffs. Existing application domain data and behavior remain project-owned.

## 1.0.0 — 2026-09-30

Initial shared Meridian identity, three themes and three layout modes; semantic token source and build outputs; local fonts and existing Meridian mark; seven Vue primitives; CSS recipes; Vuetify/Ionic/chart adapters; visual reference, inventory, integration guidance and per-project migration prompts. Existing applications remain unchanged.
